## Hi there 👋
Entelina
一个正在筹备中的 AI 共创社区。
中文名「来希」，取自希腊语 entelecheia（隐德来希，潜能实现为现实）。这个名字说的是我们关心的事：把还没成形的东西，一点点做出来。
已经做出来的
- 官网 —— 41 个静态页面，记录社区的方向、规范、工具与作品
- 两款本地工具 —— 在浏览器里运行，不调用 AI 模型，也不上传你的输入
  - Brief 结构化创作简报
  - Index Markdown 阅读结构
还没做的
- 社区仍在筹备中：账号、投稿接收、讨论入口均未开放，也没有承诺开放时间
- 不公布社区人数、历史成绩与合作方
- 作品第 000 期为品牌习作样刊，不代表真实的社区评选
我们在做什么
研究、开发、设计与知识整理，都可以是共创的一部分。
先做能用的东西，再谈规模。
官网 → https://entelina.com
